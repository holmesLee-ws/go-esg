# go-esg

ESG·지속가능경영을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 중대성 평가, 지속가능성 공시(KSSB·ISSB·ESRS), 온실가스 회계와 배출권거래제, 공급망 실사, ESG 거버넌스와 평가 대응을 다룹니다. 한국 법·제도·기준을 뼈대로 하고, 글로벌 기준과 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 실무자·관리자가 자기 회사 상황으로 배우고, 업무에 가져갈 산출물 초안(중대성 평가표, 배출량 산정 계획, 공시 준비 로드맵, 협력사 실사 체크리스트)을 직접 만들도록 짜여 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 공개 리포라 초대 없이 받을 수 있습니다. 터미널에서 `gh auth login`으로 한 번 로그인합니다. 시작하는 데 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-esg
```

**Claude Code**

```bash
cd ~/Desktop/go-esg
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-esg` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 지금 어떤 일을 하는지(직무, 업종·규모 정도) 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. ESG가 처음이면 이 단계는 생략합니다. 회사 이름은 묻지 않습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 업무 산출물 초안은 내가 쓰고 튜터가 검토합니다.
4. 법령·기준의 시행일, 적용 대상, 기준값은 자주 바뀝니다. 튜터는 이런 사실을 말할 때 공식 출처(국가법령정보센터, 금융위원회, KSSB, IFRS 재단, EU 등)를 그 자리에서 확인하고 주소를 남깁니다. 이 워크스페이스는 법률·회계 자문이 아니므로, 우리 회사의 실제 적용 여부는 담당 전문가와 확인하세요.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 상황으로 해 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역 A·D·C·V·G]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML(`studio/`), 내 업무 산출물 초안(`work/`). 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 산출물 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달됩니다. 회사의 실제 배출량 원자료, 협력사 명단, 내부 보고서 같은 민감한 정보는 대화에 넣지 말고 익명화한 값이나 예시 값을 쓰세요.
